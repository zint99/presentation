CONTEXT · 在物理设计流程中定位

GPL 决定整体分布，DPL 完成合法落位

输入：网表、单元尺寸、core / rows、固定对象、I/O 与区域约束。

GEOMETRY · 四类对象

优化变量是单元中心，连接端点是 pin

Movable cell：中心坐标 (xᵢ, yᵢ) 可变。

Fixed macro / blockage：占空间但不参与移动。

Pin：位置 = cell 中心 + 变换后的 offset；I/O 可提供固定端点。

Net：连接多个 pin 的超边，不能只看 cell 中心距离。

尺寸、坐标、pin offset 和可移动状态，共同决定正确的力。

TWO FORCES · 两种相反的趋势

只追求短线长，会把电路拉成一团

线长力：连接越近越好。

密度力：为每个单元分配足够空间。

均匀不是目的本身：还要兼顾关键路径、宏块通道和可布线性。

布局的难点，是在连接结构和空间容量之间持续寻找平衡。

OBJECTIVE · 固定一轮权重时的模型

把位置优化写成两个主要代价

minz ∈ Ω　Wγ(z; ω) + λ D(z)

z：所有可移动中心；Ω：允许移动的区域。

Wγ：平滑线长，ω 是 net 权重。

D：静电密度能量；λ 平衡线长与疏散强度。

γ、λ、net 权重与虚拟面积会变化：整个运行不是固定目标的单次下降。

ALGORITHM · 先记住这张图

完整算法是一条内循环，外加两种反馈

起点：建立布局模型；可选 B2B 初始布局。

高频循环：算线长力与密度场 → 更新位置 → 检查步长。

低频反馈：在合适阶段评估时序和拥塞，再修改模型继续迭代。

Initial placement 提供起点；Nesterov placement 负责主要优化。

INITIAL PLACEMENT · 可选的线性求解

初始布局：用 B2B 弹簧得到有结构的起点

每个方向分别找 net 的极值 pin，把边界端点与其他端点连接。

wᵢⱼ ∝ 1 / max(|xᵢ − xⱼ|, ε)

固定端点进入右端向量；可移动端点进入稀疏矩阵。

更新 pin 极值和权重，再解 x / y 两个系统。

稀疏 B2B 模型降低连接复杂度，但此时还没有解决重叠。

WORKED EXAMPLE · 等权弹簧的一维切片

两单元手算：固定端点如何确定位置

E = ½[x₁² + (x₁−x₂)² + (x₂−10)²]

对 x₁、x₂ 求导并令其为零：

2x₁ − x₂ = 0
−x₁ + 2x₂ = 10

x₁ = 10/3，x₂ = 20/3。 两条方程残差均为 0。

有锚点的连接决定相对位置；没有面积约束，单元仍可能重叠。

METRIC · HALF-PERIMETER WIRELENGTH

HPWL：用包围盒估计一条 net 的线长

HPWLₑ = (xmax−xmin)
　　　 + (ymax−ymin)

示例 pin：(1,1)、(3,4)、(7,2)。

宽 6 + 高 3 = 9 个长度单位。

不含绕障、层分配、via 与详细布线拓扑。

HPWL 适合快速比较，但单独优化它会遇到不可导与梯度稀疏。

来源：WA 线长与力 ↗ · GPL 模块说明 ↗10 / 56

WEIGHTED AVERAGE · 一个方向的公式

WA：把 max / min 换成平滑的加权平均

μ⁺ = Σ xᵢexᵢ/γ / Σ exᵢ/γ
μ⁻ = Σ xᵢe−xᵢ/γ / Σ e−xᵢ/γ
Wγ,x = μ⁺ − μ⁻

γ 大：更平滑，极值选择更柔和。

γ → 0⁺：μ⁺ → max x，μ⁻ → min x。

WA 不是 log-sum-exp；这里使用的是指数加权的坐标平均。

来源：WA 线长与力 ↗11 / 56

DERIVATION · 先归一化，再使用乘积法则

对 WA 求导，得到每个 pin 的拉力

pᵢ⁺ = exᵢ/γ / Σexⱼ/γ
∂μ⁺/∂xᵢ = pᵢ⁺[1 + (xᵢ−μ⁺)/γ]
∂μ⁻/∂xᵢ = pᵢ⁻[1 − (xᵢ−μ⁻)/γ]

数学梯度：∂W/∂xᵢ = ∂μ⁺/∂xᵢ − ∂μ⁻/∂xᵢ。

源码返回 min 导数 − max 导数，即负梯度方向。

从 pin 汇总到 cell，并乘 net 权重；固定 pin 参与算力，但不被移动。

来源：WA 导数与符号 ↗12 / 56

稳定指数计算，并随 overflow 收紧近似

DENSITY GRID · 面积而非实例数量

把连续版图切成 bins，才能计算局部容量

每个 bin 有面积 Ab 和目标密度 tb。

容量 Cb = tbAb

一个大单元跨越多个 bin，按重叠面积分摊占用。

网格太粗会掩盖热点；太细会增加计算量与数值敏感性。

要衡量“这个地方被占了多少面积”，不能只数中心点。

GEOMETRY → GRID · 从矩形到密度

Scatter：一个 cell 的面积分摊到邻近 bins

aᵢb = overlap(Rᵢ, Bb) × sᵢ

Rᵢ 是密度矩形；sᵢ 是面积缩放系数。

遍历与 Rᵢ 相交的 bin，累加实际重叠面积。

位置移动时，多个 bin 的占用连续交换。

同一个几何重叠算子，既用于密度散射，也用于电场回采样。

来源：面积散射与 overflow ↗ · 密度力回采样 ↗16 / 56

SMOOTHING · 避免小 cell 在网格内“失去方向”

密度平滑：扩大支撑范围，但守恒总面积

dx = max(w, √2·bx)
dy = max(h, √2·by)
s = wh / (dxdy)

矩形变宽，单位面积贡献相应变小。

s·dxdy = wh：总“电荷”保持一致。

密度平滑守恒面积；拥塞膨胀会增加虚拟面积，二者不同。

来源：密度尺寸与缩放 ↗17 / 56

VIRTUAL CELLS · 不写进逻辑网表

Filler：用虚拟电荷表示未被真实单元占用的空间

Afiller ≈ t·Afree − Ainst

无 net 连接，只响应密度力。

填补目标容量与实例面积的差额，让密度场有合理的平衡状态。

它们不是后续制造流程中插入的物理 filler cells。

Filler 参与密度场；报告真实拥挤程度时，overflow 分子排除 filler。

来源：Filler 初始化 ↗ · 面积散射与 overflow ↗18 / 56

CAPACITY · 几何并集比简单求和更重要

固定宏块与障碍：没有自由空间，就不能分配容量

固定对象变成不可放置面积，进入 bin 的占用背景。

POISSON · 密度 → 电势 → 电场

静电类比：让密集区域产生向外的力

−∇²ψ = ρ − ρ̄
D ∝ ½∫ (ρ−ρ̄)ψ dA
E = −∇ψ

ρ：归一化密度；ρ̄：空间平均。

ψ：电势；D：静电能量；E：电场。

高密区域对远处也有影响，不只推动相邻 bin。

电场来自整个密度分布；并非把每个热点独立地推向最近空格。

来源：CPU DCT Poisson 求解 ↗ · 密度力回采样 ↗21 / 56

SPECTRAL SOLVE · CPU 使用 DCT / 混合正弦余弦逆变换

在频域求 Poisson：微分变成乘法

ψ̂uv = ρ̂uv / (ku²+kv²)
ψ̂00 = 0

① 密度网格做 DCT。
② 每个非零频率除以波数平方。
③ 逆变换得到电势与两个电场分量。

规则网格上的变换通常为 O(B log B)，B 是 bin 数。

零频必须单独处理；非方形 bin 的两个方向尺度也不能混用。

来源：CPU DCT Poisson 求解 ↗22 / 56

GRID → GEOMETRY · 密度力的最后一公里

Gather：把 bin 电场积分回每个 cell

FD,i ≈ Σb aᵢb Eb

用相交面积乘该 bin 的电场，再对覆盖区域求和。

大单元往往得到更大的原始密度力。

因此后面还需要预条件，统一不同单元的移动尺度。

Scatter → Poisson → Gather，是密度计算最值得记住的数据流。

来源：密度力回采样 ↗ · 面积散射与 overflow ↗23 / 56

PENALTY SCHEDULE · 用 HPWL 变化控制增长

λ 随迭代变化，把拥挤布局逐步展开

λk+1 = φk λk
Δ = (HPWLk−HPWLk−1)/Href

HPWL 改善时，允许更积极增加密度压力。

HPWL 变差时，增长因子按 Δ 调整，并设下界。

实际 φ 还受动态调节与恢复逻辑影响。

ACCELERATED UPDATE · 两套坐标

Nesterov：在外推位置计算下一步

uk+1 = yk + αkd(yk)
xk+1 = ΠΩ(uk+1)
yk+1 = ΠΩ[uk+1 + βk(uk+1−xk)]

x：基础点；y：外推点；u：未裁剪试探点。

ak+1 = (1 + √(1+4ak²))/2
βk = (ak−1)/ak+1；ΠΩ 表示边界处理。

沿当前方向移动，再利用历史位移外推；边界处理限制可行范围。

ONE ITERATION · 数据依赖优先于函数名字

把一轮循环展开：昂贵工作发生在哪里

  1. 计算动量系数，生成试探坐标。
  2. 更新 pin / bin，完成 WA 与 Poisson。
  3. 合成力，估计步长；必要时重试。
  4. 接受状态，更新 overflow、λ 与平滑系数。
  5. 触发时序 / 拥塞反馈，检查收敛与异常。

优化运行时间时，先统计每轮算了几次场、多少次反馈与重启。

ROBUSTNESS · 处理模型变化和发散

快照与回退：保存的是一致状态，而非一张坐标表

快照可能涉及坐标、梯度、罚系数、动量与线长平滑系数。

TIMING LOOP · 布局位置改变关键性

时序驱动：让关键连接更有“拉力”

位置 → 估计寄生 → STA / resizer → net slack。

选出较关键的 nets，增加它们在线长目标中的权重。

后续优化缩短关键连接，再评估新的关键路径。

反馈在 overflow 阶段条件下触发，不是每轮完整跑 STA。

关键路径是动态的：布局改变延迟，延迟又改变布局优先级。

来源：TimingBase · net 重加权 ↗ · 时序反馈编排 ↗35 / 56

REWEIGHTING · 在选中的关键 net 集合内

从 slack 到 net 权重：线性映射的可解释例子

ω(s) = 1 + (ωmax−1)
　　　 · (smax−s)/(smax−smin)

例：smin = −100 ps，smax = 0，ωmax = 5。

slack −100 / −50 / 0 ps
对应权重 5 / 3 / 1。

未获得有效 slack 或未进入加权范围的 net 保持基础权重。

TAIL METRIC · 热点不能被大片空白稀释

RC metric 关注最拥塞的尾部，而非全芯片平均

把拥塞值排序，分别取最高 0.5%、1%、2%、5% 的平均。

RC = Σ kⱼ·RCtop-j / Σ kⱼ

GRT 路径还比较水平 / 垂直方向的尾部值。

此处 RC 指 routing congestion，和电学 R、C 参数不是同一概念。

评价指标决定优化重点；全局均值可能掩盖少量致命热点。

INFLATION · 从 routing 信息到 density 力

膨胀：让拥塞区域的 cell 在模型里“更占地方”

r = min(rmax, (c/c₀)p)，c ≥ c₀
w′ ≈ w√r，h′ ≈ h√r

c：tile 拥塞；c₀：膨胀阈值；r：面积倍率。

真实 master 尺寸不因这种膨胀而改变。

新增虚拟面积先消耗 filler / 空间预算。

拥塞膨胀增加模型面积；密度平滑只是重新分布同一面积。
