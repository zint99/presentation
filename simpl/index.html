论文中的路线 A

力导向二次布局

把连线视为弹簧，反复求解稀疏线性系统。

计算快，但如何确定展开力的方向与大小是关键。

代表：Kraftwerk2、FastPlace3、RQL。

论文中的路线 B

非凸优化布局

将平滑线长与密度项放进目标函数，用非线性优化求解。

论文报告当时部分实现质量好，但运行较慢，框架也更复杂。

代表：APlace2、NTUPlace3、mPL6。

SimPL 的切入点：保留二次求解的效率，用近似可行布局指导展开。

来源：§1、§3，pp.105–107。此比较反映论文发表时的研究背景，不是当前算法排名。

The placement problem

线长越短，单元越容易挤在一起

OBJECTIVE

最小化半周长线长 HPWL

每条网络的包围盒宽度与高度之和。

HPWL = Σe (Δxe + Δye)

展开单元需要空间，也会付出线长代价。

容量约束

区域内的单元面积不能超过可用放置容量。

固定对象与障碍物

必须考虑被占据的位置，以及其他区域剩余的空间。

来源：§2，p.106。

Quadratic placement

用稀疏线性系统优化线长

Qxx = −bx

Jacobi 预条件 + 共轭梯度法

X / Y 分别求解。固定本轮模型后，计算简单、结构稀疏。

求解器本身不消除重叠。

Bound2Bound 网络模型

边权与距离倒数相关。位置变化后，重新构建模型。

来源：§2、§4.1，pp.106–108。B2B 图为单方向原理示意。

Step by step

推导①：从一条边到矩阵方程

  1. 固定本轮边权，只看 X 方向

    E(x) = ½ Σ(i,j) wij(xi − xj)²

    求导时 w 固定。乘上统一的 ½ 不改变最优位置。

  2. 对一个可移动单元求导

    ∂E / ∂xi = Σj wij(xi − xj) = 0

    固定节点的坐标是常数，可移动节点的坐标是未知量。

  3. 把固定节点移到右端

    (Σjwij)xi − Σj∈Mwijxj = Σf∈Fwifaf

    M 为其他可移动邻居，F 为固定邻居，a 为固定位置。

  4. 组装所有单元的方程

    Qx = c = −b

    Qii = 相连权重之和；Qij = −wij；ci = Σfwifaf。

依据：§2，pp.106–107。公式按统一 ½ 约定教学展开。

Step by step

推导②：一个可以手算的线性系统

  1. 两颗可移动单元，三个单位权重弹簧

    固定点 0 ─ x₁ ─ x₂ ─ 固定点 10

    这是教学网表，坐标与权重不来自论文基准。

  2. 写出能量并求导

    E = ½[x₁² + (x₁−x₂)² + (x₂−10)²]

    平衡条件：2x₁ − x₂ = 0；−x₁ + 2x₂ = 10。

  3. 矩阵形式与解析解

    Q = [ 2, −1 ; −1, 2 ]　c = [ 0 ; 10 ]

    x₁ = 10/3 ≈ 3.333；x₂ = 20/3 ≈ 6.667。

  4. 位置求出来了，面积约束仍不在方程中

    这里没有单元宽度、row/site 或密度项。二维大网表同样可能在短线长位置聚集。

依据：§2 二次模型；数值例为自构造教学示例。

Step by step

推导③：B2B 为什么能对应 HPWL？

  1. 令一条 net 有 p 个端点

    L = xmax − xmin

    端点间连一条边，每个内部端点分别连到 min 与 max。

  2. 所有 B2B 边的长度之和

    Σ边d = L + (p−2)L = (p−1)L

    任一内部点到左右边界的距离之和都为 L。

  3. 在当前构模位置取权重

    w = 1 / [(p−1)d]
    Σ边wd² = Σd/(p−1) = L

  4. 坐标一变，权重就需要更新

    等式成立于构模位置。将内部点 2 移到 4，保留旧权重后 Σwd² ≈ 10.833，而 HPWL 仍为 10。

    若能量统一乘 ½，对应 L/2，最小点不变。零长度边需数值正则化。

四端点的具体例子

x = [0, 2, 7, 10]

边长：10、2、8、7、3

长度和：30 = 3 × 10

Σwd² = 30 / 3 = 10

与本方向 HPWL = 10 一致

依据：公式5、§2，p.107。数值例为教学构造。

The SimPL loop

每一轮都重新预测可行位置

初始布局：交替构建 B2B 与求解，通常 5–7 轮稳定。

01

前瞻合法化

从当前布局生成近似可行的位置。

02

更新锚点

连接单元与目标位置，调整伪网权重。

03

更新 B2B

按新位置更新真实网络的图与边权。

04

线性系统求解

产生新的数值布局，判断是否继续。

结束后取最后的近似可行布局，再做最终合法化与详细布局。

来源：图2、§4，pp.107–110。

Nonlinear scaling

不同空间容量，使用不同缩放比例

条带内线性，整体非线性

沿障碍物边界形成条带。排序后按可用容量分配单元，再在各条带内部缩放。

尽量保留相对顺序，减少对已有线长优化的破坏。

Ⅰ

划分条带

条带容量扣除固定障碍物。

Ⅱ

排序与分配

按相对切线的距离保持几何顺序。

Ⅲ

交替递归

水平、垂直方向轮流处理子区域。

Force modulation

逐渐增强锚点的拉力

wpseudo ∝ α / distance

α 随迭代增加

前期给线长优化更多自由度。后期强调向近似可行位置靠拢。

固定锚点不增加未知变量数

更新矩阵的对角元素与右端项，保留稀疏线性系统结构。

展开方向与拉力大小
都来自可解释的反馈机制。

来源：图6、§4.3，pp.109–110。

Step by step

推导④：锚点怎样修改线性系统？

  1. 单元 i 连接固定锚点 aᵢ

    Eanchor = ½ λᵢ(xᵢ − aᵢ)²

    本轮 λᵢ 固定。按伪网模型，λᵢ 与 α / dᵢ 相关。

  2. 展开能量并求导

    ∂Eanchor/∂xᵢ = λᵢxᵢ − λᵢaᵢ

    锚点坐标是常数，不新增未知量。

  3. 更新矩阵与右端项

    Q′ = Q + diag(λ)　c′ = c + diag(λ)a
    Q′x = c′

    只增加对应对角项和右端项，不增加未知变量数。

  4. 下一轮重新更新

    真实算法重新产生锚点、更新距离相关权重，并逐渐提高 α。不是一次固定惩罚就结束。

依据：§4.3、图6，pp.109–110；矩阵展开为教学推导。

Step by step

交互求解：拉力变强后，平衡位置如何变化？

蓝色为固定端点，橙色为精确求解位置，青色虚线为锚点。

Q′ = [2+λ, −1; −1, 2+λ]
c′ = [λ; 10+9λ]

沿用两单元示例，锚点 a = [1,9]。每次调节都精确求解此 2×2 系统。统一 λ 是教学参数，不等同于 SimPL 的距离相关伪网权重或完整迭代。

依据：§4.3 的锚点反馈；参数和网表为教学构造，结果实时求解。

What to remember

近似可行布局是优化过程中的反馈信息

最重要的机制

二次优化缩短连线。
前瞻合法化寻找空间。
锚点让两者相互作用。

解读结果时的边界

HPWL 优势不自动等于布线后时序优势。

前瞻合法化仍需最终合法化。

历史基准结果不代表所有现代设计。

拥塞、时序等扩展，可以利用可行布局提供更可靠的评估位置。

来源：§3、§7，pp.107、112–113。
